# 🏪 بقالة العزي - تطبيق فواتير ونقاط بيع أندرويد (POS)

تطبيق متكامل لنقاط البيع وإصدار الفواتير مصمم ومخصص لهواتف وأجهزة أندرويد اللوحية، يدعم الطباعة الحرارية والمزامنة المحلية وتصدير البيانات.

---

## 📱 بناء ملف الـ APK تلقائياً عبر GitHub Actions:

تم تضمين ملف سير عمل تلقائي داخل المجلد:
`.github/workflows/build-apk.yml`

### خطوات الحصول على تطبيق الأندرويد (.apk):
1. عند دفع الكود (Push) إلى مستودعك في GitHub، سيبدأ GitHub Actions بالبناء تلقائياً.
2. ادخل على تبويب **Actions** في مستودعك على GitHub.
3. اضغط على أحدث تشغيل (Workflow run) بعنوان **📱 بناء تطبيق أندرويد (APK)**.
4. بعد اكتمال البناء (ستظهر علامة صح خضراء ✅)، انزل لأسفل الصفحة إلى قسم **Artifacts**.
5. اضغط على **Azizi-POS-Android-App** لتحميل ملف الـ APK مباشرة وتثبيته على هاتفك.

---

## 🚀 تشغيل التطبيق محلياً للتطوير:

```bash
# 1. تثبيت الاعتماديات
npm install

# 2. تشغيل السيرفر المحلي
npm run dev

# 3. بناء نسخة الإنتاج
npm run build
```
